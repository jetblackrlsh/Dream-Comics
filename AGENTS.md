# Agent Instructions

## Dream Comic Identity

- Do not put an issue number on a Dream-Comics cover.
- Dream-Comics entries are identified by their date, using the dated comic folder and visible date/title context rather than issue numbering.
- When generating or revising cover prompts, omit issue-number language unless the user explicitly asks for an exception.

## Workflow Authority

- Follow the workflow files and skills in this repo when they define comic generation requirements.
- For comic-book PDF page artwork, use the built-in in-chat AI image generation tool required by `skills/comic-book-pdf/SKILL.md`; it does not require an API key.
- Do not use Pillow, canvas drawing, SVG, HTML/CSS, or other local drawing/compositing code to generate comic-book pages as a substitute for the in-chat AI image generation tool.
- Pillow may be used only for workflow-supported assembly, preview, inspection, or format normalization after the page artwork has already been generated by the in-chat AI image generation tool.
